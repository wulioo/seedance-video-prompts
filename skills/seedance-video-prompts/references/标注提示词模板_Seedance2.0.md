# 标注提示词模板：Seedance 2.0

依据：[2.0 官方指南](https://docs.volcengine.com/docs/82379/2222480?lang=zh)的基础公式、进阶公式、特殊字符规范与附录案例。以下是**依据官方规则定制的模板**，不是官方提供的固定格式。

交付遵循 [SKILL.md 的规则优先级](../SKILL.md)：模型能力与提示词写法先服从 2.0 官方知识，剧本、分镜和参考图用于确认本次创作事实。只有缺失、冲突或重要补全会影响结果时，才在正文外简短说明。下列模板与示例是可选辅助，不是必须套用的固定格式，也不能作为项目事实来源。

## 字段标注

| 标注字段 | 用途 | 何时保留 |
|---|---|---|
| 任务与素材绑定 | 区分参考、编辑、延长；把编号对应到角色和参考维度。 | 有素材或非新生成任务时。 |
| 主体与环境 | 唯一角色标签、稳定特征、地点、光色与关系。 | 通常需要，可融入一句开场。 |
| 镜头N | 按顺序描述摄影、具体动作、变化与声音。 | 多镜头时；单镜头不凑分镜。 |
| 全局风格与约束 | 统一质感、风格、连续性和用户要求。 | 只保留有作用且不冲突的内容。 |

以下 `〔……〕` 是填写占位符，生成成品时全部替换或删除。注释说明不混入成品。镜头序号不代表固定秒数。

素材绑定默认按职责分行或分成短段：场景、人物、道具、构图／位置、音频等分别独立表达，不要把多个 `@素材` 和职责压成一个长段。素材绑定结束后空一行；单镜头正文继续按摄影／环境、开场状态、连续动作与对白、结尾和全局约束自然分段。默认省略栏目标题，除非用户明确要求；多镜头按事件顺序编号。`【】` 只标注需要生成的屏幕文字，不用于栏目排版。这些排版选择不属于官方强制格式。

运镜与音色选词见[官方关联专题](关联写作知识_Seedance2.0.md)。多宫格与独立分镜图可用于构图/顺序参考，但不套用2.5的格数建议或首尾帧锁定规则。涉及实际输入角色时查[参数限制](生成参数与素材限制.md)。

## 新视频/素材参考默认模板

默认使用此全能参考模板。只有用户明确选择首尾帧模式时，才改为对应模式；分镜或素材中出现首尾画面要求仍可按全能参考描述，不自动切换。

```text
〔参考 @图片1 中的主体，保持本镜需要继承的主要属性。〕〔参考 @图片2 的场景、布局或光线。〕

〔地点和时间〕。〔拍摄对象、景别和一种主要运镜〕。〔主体连续完成的动作与画面变化〕。〔必要声音〕。〔整体风格及少量必要约束〕。
```

图片中只有一个明确主体时，不为凑格式补写外观清单。多主体、多素材分工、多镜头、编辑、延长或已出现生成偏差时，再使用下文对应的增强模块。

只有用户明确要求纯文本任务时才删除第一段素材绑定，用文字直接定义角色。默认全能参考尚未上传素材时，须先通过 SKILL.md 的场景参考图关卡或取得用户明确同意缺图继续，才在正文外列出“建议上传顺序（待上传）”，再按该映射撰写条件明确的提示词，不将编号表述成已经上传。用户要一镜到底时，把镜头拆分改成同一个连续镜头里的事件顺序，不人为加入切镜。

主体标签也适用于需精准引用的道具和场景。后续动作、位置及声音归属保持清楚即可；单主体连续动作允许自然代词或承接省略，多主体交替和局部动作可能产生歧义时再重复名称或身体部位。

素材绑定用最少但足够的描述：单一明确对象可以直接用类别定位；多个相似对象再补区分特征，不机械凑满2–3项。识别特征与参考范围分别说明，关键剧情细节仍保留。以下示例以每张待上传图均能唯一识别相应对象为前提。

多个素材属于同一主体时应合并绑定；复杂映射可逐行写成：

```text
将 @图片1 中短发、穿灰色长衫的男子定义为角色A，角色A的面容参考 @图片1。
@图片2 中穿同款灰色长衫的男子与角色A为同一主体，角色A的衣装参考 @图片2。
```

## 原创参考示例：单镜头人物反应

这是依据官方组织方式编写的示例，不是官方案例原文。假设分镜已指定角色、场景和道具，但图片尚未上传，应先在正文外说明：

建议上传顺序（待上传）：`@图片1`＝角色定妆图，参考面容与衣装；`@图片2`＝档案室场景图，参考工作桌布局与灯光；`@图片3`＝记录簿道具图，参考外形与材质。以下正文按此顺序编写，需上传对应图片并匹配编号后使用。

```text
参考 @图片1 中的档案员，保持人物面容与衣装一致；参考 @图片2 的档案室、工作桌布局与灯光；参考 @图片3 中记录簿的外形与材质。

白昼，档案员坐在档案室的工作桌前，合拢的记录簿放在右手旁。固定机位，从右前方拍摄人物中近景，同时带到侧脸、右手与桌上的记录簿。他低头注视记录簿，右手缓慢移过去，掌心轻而坚定地压住封面，<纸封轻响>，肩背保持原朝向。写实生活电影质感，自然窗光，一个连续镜头，无对白，无字幕。
```

## 编辑与延长替换模块

### 原视频编辑

```text
严格编辑 @视频1：将〔可识别对象〕的〔原属性〕修改为〔新属性或 @图片N 中的具体特征〕。
〔若为增加：写清对象特征、出现位置和剧情中的出现时机。若为删除：明确删除对象。〕
保留〔用户要求不变的主体/动作/场景/运镜/声音〕。
```

删除“修改”模板中与当前操作无关的内容，不把“参考 @视频1 生成……”作为编辑开头。

### 向前/向后延长

```text
向〔前/后〕延长 @视频1，〔承接原片开头/结尾状态的新事件〕。
〔主体〕〔连续的动作与反应〕，镜头〔主要摄影方式〕，〔声音衔接〕。
〔需要持续一致的角色、环境、光色和风格〕。
```

### 两片之间补齐

```text
@视频1，〔连接前片结尾与后片开头的动作、场景变化和摄影路径〕，接 @视频2。
```

## 声音与文字插槽

按需放入具体镜头，不要求每条都使用：

- 对白：`角色A轻声说{〔台词〕}`；小语种加语种。
- 音效：`<〔与画面动作对应的声音〕>`。
- 音乐：`（〔音乐类型与节奏〕）`。
- 字幕：`〔出现时机与位置〕显示【〔字幕内容〕】，〔同步与样式要求〕`。

## 多图与动作、运镜、特效参考

以下是按官方附录整理的职责句式，只保留本任务实际素材，填写后接具体事件：

```text
将 @图片1 中的〔可辨认对象〕定义为〔主体名〕。
@图片2 中的〔对应对象〕与〔主体名〕为同一个主体，@图片2 仅补充〔服装/道具侧面/材质等〕。
@图片3 用于〔场景或独立分镜构图〕，〔明确场景标签与用途〕。
参考 @视频1 中〔指定对象〕的〔动作/运镜/特效〕，由〔目标主体〕完成〔事件〕。
〔如有Logo：在事件收束时于指定位置显示 @图片4 中的Logo。〕
```

若一份视频同时提供多个维度，要具体点名；角色左右位置与原动作对应。人物身份、场景和特效不能被多个参考源争夺。Logo已被要求时不附加“无Logo”。

## 原创完整示例：茶馆内的短剧情

本例无参考素材，是根据官方组织风格创作的新例子。

```text
雨后傍晚，一间木质茶馆内，短发、穿深绿色针织衫的女店主正收拾靠窗的茶桌。窗外石板路泛着微光，室内暖灯映在白瓷杯沿。

镜头1：女店主的中景，镜头平稳横移。女店主右手握住杯柄，缓慢把茶杯放回托盘，指尖轻轻转正杯柄，<杯底轻触瓷盘声>。
镜头2：切至女店主面部近景，固定机位。门外响起<两下轻缓的敲门声>，女店主抬眼看向门口，原本收紧的眉头舒展开，轻声说{还留着你的位置}。
镜头3：靠窗茶桌的近景，固定机位。女店主将另一只茶杯轻轻推向空座前，杯中的热气缓缓上升，窗外的雨滴从屋檐落下。

整体为写实生活电影风格，暖灯与雨后微冷的天光自然交融，木纹和瓷器质感清晰，人物外观保持一致。保留轻微雨声，不添加字幕。
```

## 使用检查

先通过[交付门禁](交付门禁.md)，再使用以下格式检查；核心事件没有可执行关系或必要镜头证据时，不得交付完整提示词。

1. 用镜头顺序而非强制精确时间戳。
2. 动作细节明确，但没有把完整长剧本塞进短片。
3. 参考任务在正文以 `@图片N`、`@视频N`、`@音频N` 明确绑定用途；编号对应已上传映射或已标明的待上传清单。纯文本任务没有假编号，未上传不等于纯文本任务。
   - 定位素材中的具体人物、道具和场景；同一主体的多个素材统一绑定，不同主体分别定义。正文保持主体归属清楚，不要求逐句机械重复标签。
4. 用户要求的字幕、Logo等不会被通用限制抵消。
5. 编辑、延长目标没有被误写成参考来源。
6. Seedance 2.0 的背景音乐／持续声场、音效、对白和字幕分别使用`（……）`、`<……>`、`{……}`、`【……】`；不存在的声音或文字不补造。
