# 标注提示词模板：Seedance 2.5

依据：[2.5 官方指南](https://docs.volcengine.com/docs/82379/2607689?lang=zh)、其明确推荐的官方`sd25-pe 0.1.1`、已读取的[飞书补充指南](飞书补充写法_Seedance2.5.md)及[参数限制](生成参数与素材限制.md)。以下是归纳后的本技能定制结构，保留用户排版偏好。详细素材、母版与边界规则见[素材与任务编排](素材与任务编排_Seedance2.5.md)。

交付遵循 [SKILL.md 的规则优先级](../SKILL.md)：模型能力与提示词写法先服从 2.5 官方知识，剧本、分镜和参考图用于确认本次创作事实。只有缺失、冲突或重要补全会影响结果时，才在正文外简短说明。下列模板与示例是可选辅助，不是必须套用的固定格式，也不能作为项目事实来源。

## 字段标注

| 标注字段 | 用途 | 写法 |
|---|---|---|
| 素材映射 | 为多模态输入分配职责。 | 按实际上传编号逐项绑定外观、声音、动作、场景等。 |
| 一句话概述 | 概括视频的创作目标。 | 谁、在哪里、发生什么、什么题材/风格、重要摄影特征。 |
| 情节/时间轴 | 描述叙事与声画关系。 | 可选镜头序号或整数秒连续时间段。 |
| 全局要求 | 补充贯穿画面的规则。 | 场景、摄影、氛围、声音和字幕等。 |
| 平台设置 | 处理编辑/延长/首尾帧任务的参数。 | 放在提示词外，只给实际需要的设置。 |

以下 `〔……〕` 是可替换字段。成品须替换全部占位符，删去没有素材或没有需求的栏目。不要把样例三段时长当作固定标准。

成品默认省略栏目标题，必要素材可在一句或一个短段中清楚引用，不要求每项独占一行；复杂映射再逐行列出。保留用户原编号；待上传映射明确标为建议顺序。2.5 可用官方技能列出的声音符号，也可用主指南的自然语言，不强制符号或栏目。

景别描述按用户写作约定同时点明拍摄对象，例如“角色A的中近景”“角色A与角色B的双人中景”；局部特写写清归属。这是表达清晰度约定，不是2.5官方的固定句式要求。

## 新视频/参考生成默认模板

默认按全能参考编写；首尾画面、关键帧或已上传两张图片不自动触发首尾帧模式。只有用户明确选择该模式时使用下方严格首尾帧模块，其他情况下保留语义参考和素材职责。

```text
〔参考 @图片1 中的主体，保持本镜需要继承的主要属性。〕〔参考 @图片2 的场景、布局或光线。〕

〔主体、地点和核心事件〕。〔拍摄对象、景别和一种主要运镜〕。〔连续动作、互动与画面变化〕。〔必要声音〕。〔整体风格及少量必要约束〕。
```

图片中只有一个明确主体时，不为凑格式补写外观清单。多主体、多素材分工、多镜头、编辑、延长、关键帧或已出现生成偏差时，再使用下文对应的增强模块。

需要时间控制时，可按官方推荐使用连续整数秒时间段；否则按镜头、阶段或自然段组织，不因只给了生成时长就机械新增数字时间段。用户需要单镜头时写成连续事件，不插入与其矛盾的切镜。参考视频已准确表达的动作和运镜可直接绑定，不必照模板重述。只有实际提交到生成端但明确不采用的素材，才按需说明编号与不采用范围，不虚构编号。

## 任务替换模块

### 局部编辑

```text
@视频1 是唯一编辑母版。
编辑 @视频1，仅在〔用户需要的时间范围〕将〔目标对象的原状态〕改为〔新状态〕，变化过程为〔用户需要的过程〕。
〔目标对象〕继承〔原对象〕的出现、移动、遮挡与离开关系。
除上述明确修改对象外，@视频1 中其余人物、道具、背景、镜头、事件顺序与声音保持原样。
```

对应设置写在正文外：`omni_reference_task_type=edit`、`ratio=adaptive`、`duration=-1`；至少一段4–30秒的reference_video；建议MOV。全片编辑删除时段限制，不凭空添加局部范围。用户要求删除其余所有对象时，按真实目标改写保留句。

### 音频编辑

```text
@视频1 是唯一编辑母版。
仅编辑 @视频1 中〔指定说话人或声音类别〕的〔对白/音乐/音效〕，将〔原内容或音色〕改为〔新内容或声音特征〕，〔用户需要的口型同步〕。
保留〔其他声音和画面要素〕，〔字幕要求〕。
```

### 延长

```text
向〔前/后〕延长 @视频1。
〔向后时新增片段开头承接原片尾帧；向前时先写前置事件，新增片段结尾接原片首帧。保留本次方向对应的一种。〕
〔新事件及镜头发展，声音承接要求〕。
〔主体作为同一连续对象，边界姿态、道具位置、空间、光线、运动趋势与声音保持连续。额外参考不覆盖原视频边界。〕
```

正文外说明 `omni_reference_task_type=extend`、`ratio=adaptive`，输入输出宜用MOV；新增时长根据用户目标设置。不要承诺音量绝对不变。

### 独立关键帧

```text
以〔按实际上传编号列出的图片顺序〕作为关键帧。
〔故事概述〕。〔关键帧之间的行动、镜头衔接、对白和声音〕。
〔全局风格与要求〕。
```

只有用户明确选择首帧/首尾帧模式时，才改用对应任务并在平台/API设`first_frame/last_frame`。不能在多关键帧/全模态请求里混加这些角色；全能参考中开头/结尾的画面要求保持语义参考，不自动切换，也不承诺锁定画幅。

### 多宫格故事板

```text
@图片1 是线稿故事板，用于剧情和镜头结构，按〔读取顺序〕使用；〔其他实际素材与角色/场景映射，每项一行〕。
〔线稿画风、文字标注或占位人物中哪些不采用；目标画风为线稿时不误删该风格。〕
〔故事概述〕。
镜头1：〔补齐线稿未提供的动作、摄影、声音与风格信息〕。
镜头2：〔下一格对应的连续剧情〕。
〔继续到本次实际使用的最后一格，不臆造未见的图格内容〕。
〔全局要求〕。
```

故事板不是严格画面对齐保证；用户需要逐图更强控制时，使用独立关键帧方案。

### 白模渲染

```text
@视频1 为〔粗粒度/细粒度〕白模参考，仅继承〔运镜/动作/主体运动路径/需要继承的光照变化/完整结构〕。
〔@图片N 中的角色对应白模中的哪个对象，逐一说明〕。
最终画面为〔场景、角色外观、材质、风格〕。〔符合白模的剧情与必要关键动作〕。
〔声音与全局呈现要求〕。
```

## 首尾帧与组合任务补充

以下严格首尾帧模板只在用户明确要求对应模式时使用（平台先设置角色，不与其他全模态参考混传）：

```text
@图片1 作为首帧，明确〔起始构图、主体姿态和道具状态〕。
@图片2 作为尾帧，明确〔结束构图、主体姿态和道具状态〕。
〔主体〕从首帧状态通过〔连续事件〕自然到达尾帧状态，保持〔身份、道具数量、空间与光线〕一致。
```

一键成片：

```text
将〔实际图片/视频编号〕制作成〔题材〕短片，素材顺序〔允许重排/按明确顺序〕。
〔每份素材的职责，哪些原素材内容需保留〕。
〔每张图片允许的动态幅度、剪辑节奏、转场、视觉包装位置与统一风格〕。
〔声音、文字及收束状态〕。
```

无缝转场：

```text
衔接 @视频1 与 @视频2，在两段之间生成过渡。@视频1 结束时〔状态〕，随后镜头〔路径与变化过程〕，自然到达 @视频2 开头的〔状态〕。
〔具体触发动作或遮挡物，前后形状/材质/光线如何对应，切换后保持的构图与运动趋势〕。
〔需要连续的主体和空间关系，声音从前段声源过渡到后段声源〕。
```

同时编辑并延长时分别输出两步：步骤一编辑原片；步骤二以步骤一的输出为新的延长源视频。各步只写对应任务，不把新增内容误加入原片编辑范围。

## 原创完整示例：夜间机器人投递

本例无参考素材，用十五秒连续时间轴演示本版本的组织方式；不是官方案例。

```text
写实科幻短片：雨后的旧城小巷里，一台矮小的蓝色配送机器人把最后一个包裹送到亮着暖灯的修表铺门口，画面有真实夜景光影与潮湿路面的反光。

0–4秒：机器人的低机位全景，镜头跟随机器人穿过小巷。机器人沿墙边驶向修表铺，轮子经过一小片积水，发出轻微水声，头顶的圆形指示灯照亮门槛。
4–10秒：切至门口机器人与修表师的双人中景。机器人停稳，打开胸前储物舱，将小纸盒递给穿灰色围裙的老修表师。修表师接过纸盒，抬眼露出疲惫却满足的笑容，轻声说：“今天也辛苦了。”
10–15秒：机器人与修表师的近景，固定机位。机器人朝修表师点头，圆形灯闪亮一下。修表师在门槛旁挪出一个空位，机器人缓缓驶入暖光中，门边的小铜铃轻响。

整体保持写实的金属、纸盒与石板材质，冷色巷道和温暖室内光线自然过渡。只保留对白、细雨、轮子和铜铃声音，不要背景音乐，不额外添加对白字幕。
```

## 使用检查

1. 使用时间轴时区间为连续整数秒；不使用时间轴时按镜头或阶段组织。剧情密度与总时长相称。
2. 动作以概括为主，仅突出关键细节，不重复写同一个动作。
3. 多素材映射明确，参考什么写什么，不只依赖图片里的文字标签。
4. 编辑/延长/首尾帧参数约束与用户要求相容，平台设置不冒充已执行。
5. 来源是2.5主指南、其明确引用的专题或已核验官方技能，没有误用2.0的动作偏好、上限或时间控制；官方来源冲突按对齐清单处理。
