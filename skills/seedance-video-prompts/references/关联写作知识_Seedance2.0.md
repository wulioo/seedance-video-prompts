## 镜头语言

引用链：[2.0“4 运镜写法”](https://docs.volcengine.com/docs/82379/2222480?lang=zh#96bb2087) → [1.0指南“镜头语言”](https://docs.volcengine.com/docs/82379/1631633?lang=zh#afc80793)。读取范围包括基础运镜、复杂运镜、景别和视角控制。

下表把官方术语与示例转成便于填写的画面描述，并非官方逐字释义：

| 类别 | 可用写法 | 应交代的可见结果 |
|---|---|---|
| 推 | 镜头缓慢前推至主体近景 | 从哪个景别靠近哪个主体，结尾看清什么 |
| 拉 | 镜头拉远，露出主体周围环境 | 哪些原本画外的空间进入画面 |
| 摇 | 镜头向右摇摄 | 观察方向从哪个对象转到哪个对象 |
| 移 | 镜头平稳右移 | 摄影机横向经过的主体与前后景关系 |
| 环绕 | 镜头从主体背面环绕至正面 | 围绕谁、从哪侧开始、在哪侧结束 |
| 跟随 | 镜头跟随主体前行 | 跟拍对象、路径与相对距离 |
| 升／降 | 镜头逐渐升起／下降 | 高度变化后揭示的主体或空间 |
| 变焦 | 镜头变焦聚焦主体 | 主体大小及背景可见关系如何改变，不把焦距数值当成硬锁定 |
| 固定 | 固定机位，主体在画面内行动 | 机位不动，动作与环境变化承担叙事 |

景别可直接使用远景、全景、中景、近景、特写。视角可使用水下、航拍、高机位俯拍、低机位仰拍、微距、过肩、以某对象作前景、透过某遮挡物观察等。写清观察对象与构图作用，不为展示术语而堆叠。

关联页提供多种运镜连续组合的长镜头示例；2.0主指南明确建议一个镜头尽量只指定一种运镜。默认遵循2.0主指南；用户明确需要复杂长镜头时，说明连续路径及转换关系，必要时用运镜视频参考，不将关联页示例表述为稳定性保证。

## 音色特征

引用链：2.0“音色参考不准” → [1.5 pro“声音生成／对话与画外音”](https://docs.volcengine.com/docs/82379/2168087?lang=zh#6270f91d)。该链接用于补充音色描述，不是要求导入1.5的全部语言能力、默认值或摄影规则。

官方音色描述公式：**性别＋年龄区间＋声音属性＋语速＋情绪基线**。声音属性可描述音域高低、气声比例、明亮或厚重、颗粒感、发声力度与语调起伏。只填写用户指定或可听出的属性；没有依据的年龄、性别或口音不必补造。

原创句式：`角色A的音色参考 @音频1，为低沉、略带颗粒感的男声，语速平缓，语气克制。角色A说{用户提供的台词}。` 声音特征仅为示例，按当前素材和用户要求替换。

多角色分别绑定音色与台词；画外音写明不由画内人物开口。音色参考与台词的语气、表述风格尽量接近；文字台词与音频职责须分清，不能把仅用于音色的音频内容当成新对白。

## 图片与视频参考的完整用法

来源：2.0主指南“附录：提示词案例”。

| 参考类型 | 组织方式 |
|---|---|
| 同一商品多角度 | 多图共同定义同一物体，明确正侧背面分别用于什么；不把多个角度生成成多个商品 |
| 同一人物多图 | 明确同一身份及各图用途。附录有多图人物案例，但排障章节不建议人物多视图；默认用独立人脸与造型图 |
| Logo | 指定Logo素材、出现时机、位置和背景变化；不得同时写“无Logo” |
| 多主体／多元素 | 人物、服装、场景、道具、Logo分别指向素材，不用一条范围句混合多人映射 |
| 多宫格故事板 | 交代读取顺序、镜头顺序和需要补齐的动作；不从2.5移植格数建议或画面对齐保证 |
| 独立分镜构图 | 角色图与构图图分工，写明镜头在哪张构图间切换；不等于API首尾帧设置 |
| 动作视频 | 指明原视频哪位主体的动作由新视频谁执行；左右角色关系须对应 |
| 运镜视频 | 指明只取运镜、速度或镜头顺序，另外定义目标场景和视觉中心 |
| 特效视频 | 指明要复用的特效形态、触发位置、附着主体和生成轨迹 |
| 编辑与组合 | 点名编辑对象、旧属性与新属性，说明动作、运镜等保留项；引用其他素材不改变编辑母版身份 |
| 延长与轨道补齐 | 指明向前或向后，或按“视频1→过渡→视频2”的顺序；只生成衔接所需内容，不承诺输出包含全部原片 |

## 文字生成

2.0主指南中的“文字生成”链接指回同文附录，已合并阅读，不是漏读的外部文档。

- 广告语：文字内容＋出现时机＋出现位置＋出现方式＋字形色彩；画面文字用`【】`。
- 对白字幕：指定位置、准确原文、与哪条台词或音频节奏同步。
- 气泡台词：明确说话人，气泡位于该说话人周围，气泡内容对应台词。
- 对Logo或字体外观要求精确时，可另外提供对应图，只让该图负责文字外观。
- 优先常用字；不把“支持文字生成”说成逐字无误保证。用户给出的专名仍保留，不擅自改写。

## 官方 sd2-pe 补充

2.0教程“提示词Skill”直接链接[官方sd2-pe文档](https://arkdocs.tos-cn-beijing.volces.com/files/video-generation/SKILL.md)，本轮已阅读全文，原文无版本号，哈希见来源记录。

- 复杂度按时间与空间判断：单场景的连续动作/一段台词可以直接用简洁正文；多事件、多空间或已有多镜头提示再展开。素材数量多只是信号，不代表必须多镜头。
- 引用避免裸编号直接接动词或方位，如“@图片1跑向”。改为“@图片1 中的女子”或已定义主体名。这是官方技能明确补充的断句防歧义方法。
- 八要素用于检查，不代表每项都展开长段；主体与动作明确，其余根据任务补足。非写实风格应清楚锚定，避免漂移。
- 官方技能要求通用画质/稳定/Logo等兜底、人物多视图禁用、九宫格拆图及额外披露；主指南则把不少项列为建议，且附录有分镜图/多视角参考。此处保留差异，不把优化器的保守策略说成模型硬限制，不用通用兜底覆盖用户明确的Logo、字幕、双胞胎或动态要求。
- 官方技能的“路径A”明确不要求强行加主体定义/分镜/约束栏目。这进一步支持简单单镜头使用自然段；用户确定的素材每行排版继续保留。
