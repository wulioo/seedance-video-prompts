# Seedance 2.0 常见问题与案例核对

来源：[2.0官方指南](https://docs.volcengine.com/docs/82379/2222480?lang=zh)“常见问题”全部12节及附录。核验：2026-09-12。只在实际出现对应问题时使用，不把所有补救词复制进每条提示词。

| 现象 | 官方处理及执行边界 |
|---|---|
| 人物ID漂移 | 独立人脸近照与全身造型图分工，重要素材前置；不要把脸部特写、服装、三视图拼成一张复杂人像图 |
| 自动生成字幕 | 写明无字幕；去掉参考素材中不必要的文字；业务允许时横屏生成再裁切。官方明确无法100%避免，不能保证一句无字幕即可解决 |
| Logo或水印 | 针对不需要的文字标识写限制。画面中自动生成的平台图样与API主动添加的水印是两件事，后者需检查设置 |
| 风格漂移 | 明确具体媒介与画风，参考图必要时先统一目标风格 |
| 延长接缝跳变 | 官方建议前片尾部删6帧、后片头部删1帧再拼接；这只是排障试法，按实际素材验证，不自动处理用户原片。也可让衔接发生在明确切镜处 |
| 双胞胎／重复人物 | 明确人物与素材绑定、单人独立图、精简提示词；必要时限制同一身份只有一个实例。用户本来要求双胞胎或分身时不能套此限制 |
| 多次延长画质劣化 | 减少续写次数、保留高清图；官方还建议先把原视频转换为白模再续写，是有额外成本的制作方案，不能把它等同于2.5的白模渲染全部能力 |
| 特效不合预期 | 参考具体特效视频，并绑定目标主体与特效运动；仅描述“倒计时”等未必能准确控制 |
| 超过4个参考人物不稳 | 分组制图，每组不超过4人，再用多张分组图生视频。4人是此处稳定性建议，不是硬上限 |
| 片尾噪音 | 可重生，或用音量包络线在片尾淡出至0，预览有无截断；不要把淡出放在未说完的对白中间 |
| 中文发音不准 | 用同音的常用字优化语音；保留需显示的正式字形，明确区分语音试写与字幕原文；不保证彻底解决 |
| 音色参考不准 | 参考音频之外补音色特征，台词语气与原音频接近；详细公式见[关联写作知识](关联写作知识_Seedance2.0.md) |

官方白模排障句式要点：将原视频转为白色3D模型，人物纯白，无色彩、纹理、阴影，纯白背景，保留结构与运动。是否执行转换由用户的制作任务决定，本技能只写相应提示词。

## 附录覆盖与原创写法

广告语、字幕、气泡台词、主体多视角、多图、多主体、多元素、Logo、宫格及独立分镜图、动作、运镜、特效、增删改、向前/向后延长、轨道补齐均已阅读。逐类写法见[关联写作知识](关联写作知识_Seedance2.0.md)与[模板](标注提示词模板_Seedance2.0.md)。这里只提炼任务关系，不复制原文品牌、人物、对白作为用户成品。

示例与规则出现张力时，记录而不隐藏：

- 原文案例会使用代词，但主体定义章节要求持续使用同一标签；本技能按明确规则执行。
- 原文古风案例把推进和环绕写在同一镜头，关联的1.0章节也有复杂运镜；2.0正文仍建议单镜头一种主要运镜。
- 附录有多图人物参考，并不等于建议把多人或人物多视角拼在一张图内。
- 平台教程中个别2.0示例含数字时间段，但2.0提示词主指南明确说精确时间支持不稳定，默认使用镜头顺序。

轨道补齐附录注明：最多3段参考视频，总时长不超过15秒，自动截取首尾视频的衔接部分。完整素材上限及2.0/2.5的区别见[生成参数与素材限制](生成参数与素材限制.md)。
