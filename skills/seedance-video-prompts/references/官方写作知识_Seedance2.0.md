# 官方写作知识：Seedance 2.0

依据：[Doubao Seedance 2.0 系列提示词指南](https://docs.volcengine.com/docs/82379/2222480?lang=zh)。核验日期：2026-09-12；官方更新时间：2026-09-07。下文是为提示词创作整理的规则摘要，不是官方逐字转载。栏目模板和新案例是本技能定制内容。

本轮已逐节复核主指南。运镜、音色和附录分类详见[关联写作知识](关联写作知识_Seedance2.0.md)；全部12类排障见[常见问题与案例](常见问题与案例_Seedance2.0.md)；参数边界见[生成参数与素材限制](生成参数与素材限制.md)。

## 基础任务与动词

来源章节：基础公式。

| 任务 | 写法要点 |
|---|---|
| 全模态参考 | 明确“参考哪个素材的哪个属性”，再描述要新生成的内容。图像可供主体、场景、风格参考；视频可供动作、运镜、特效、音效参考；音频可供音色等参考。 |
| 编辑 | 明确待编辑视频。增加：对象特征、出现位置、出现时机；修改：原属性变成什么；删除：删什么、保留什么。未提到的部分默认不改，必要时强调关键保留项。 |
| 延长 | 直接要求向前或向后延长指定视频，写清接续发生的事件与承接状态。 |
| 轨道补齐 | 按“视频1 → 衔接事件 → 视频2”的次序组织；有第三段时继续明确过渡。 |
| 组合 | 分清参考来源和编辑对象，例如借用图片1的外观，严格编辑视频1中的某个角色。 |

**关键区别**：编辑、延长时直接指代待处理视频，不把开头写成“参考视频1”，否则容易被理解成参考生新视频。

## 官方进阶结构的应用

来源章节：进阶公式、定义主体、使用分镜时序、动作描述要求、运镜写法、画质/风格与约束词。

按“主体身份、动作、环境、光色、摄影方式、美术风格、画面质感、必要限制”组织。重点是可执行的空间与时间指令，不是堆砌夸张形容词。

### 主体与素材绑定

来源：官方进阶公式“1 定义主体”，2026-09-12再次读取原文核对。以下覆盖基本定义、多素材同主体、多主体场景及注意事项。

- 本技能的2.0参考提示词采用显式引用写法：`@图片1`、`@视频1`、`@音频1`。例如“以 @图片1 中的人物作为角色A，采用 @图片2 的室内布局，@视频1 仅参考运镜，@音频1 用于角色A的音色”。编号须与已上传素材或明确标注的建议上传顺序对应，不是装饰性符号，也不能只在正文外列素材而不绑定用途。
- 官方`sd2-pe`补充：不要让裸引用直接粘连动词或方位（如“@图片1跑向”）；用“@图片1 中的男子”、主体名或“主体名@图片1”分清编号与对象。其全文已核验，详情见关联写作知识。
- 主体不限于人物，也包括道具和场景。一张图中可能有多个对象，需明确选取对象，不能只写笼统的“参考图片”。官方推荐句式为“将图片/视频N中的[主体核心特征]定义为[主体名]”，并建议用2–3项清晰、稳定的静态特征（服饰、发型、外观、类别等）确保唯一可识别性；为需精准引用的道具和场景同样命名。
- 用户确认的精简执行约定：按“定位对象→命名→说明参考属性”写，不为凑特征数量重述图片。图中只有一个明确对象时，“线装册”“二楼观众席”等类别即可定位；同图有多个相似对象时，再补颜色、位置、衣装或磨损等区分信息。剧情或连续性依赖的细节可另外强调。此为结合官方简洁性要求的本技能约定，不冒充官方逐字规定的例外。
- 对象识别与参考范围分开：“线装册”定位物体，“定义为记录簿”赋予标签，“保持外形与材质一致”指定参考属性。图片已经清楚提供的非关键静态细节可省略，把文字重点留给动作、顺序和变化；仍需保留用户明确指定的细节。未见图片时按已知描述或待上传映射写，不能声称已确认图中只有一个对象。
- 多素材同主体：将不同素材中的对应对象统一定义为同一个标签，可补充各图分别负责面容、衣装等属性；不能把同一个人的不同参考图定义成多个角色。多主体场景：每个对象分别定义唯一且稳定的标签，同一张图中的不同对象也要用特征区分。
- 官方要求涉及主体时指代清楚，避免因省略造成动作归属不明。素材首次出现时用“@图片N 中的主体”完成绑定；主体名称已经建立后，无需反复追加素材编号。
- 指代清楚不等于逐句机械重复角色全名。单主体场景允许使用自然代词或承接上句省略主语；多主体、动作交替或局部特写可能产生歧义时，再明确写出角色名称、身体部位或道具归属。
- 使用 Asset ID 的素材也要在文字里按图片/视频编号引用；不要直接把 Asset ID 当成可理解的主体名称。
- 描述保持简洁，避免冗余和同一主体特征互相矛盾。复杂空间关系优先借助参考图，文字补充必要关系即可。

官方实战案例中存在自然代词和动作省略，实际执行以“主体归属清楚”为判断标准，不把统一标签误解成禁止自然语言承接。

### 景别与拍摄对象

2026-09-15核对[官方主指南](https://docs.volcengine.com/docs/82379/2222480?lang=zh)：“定义主体”要求“每次涉及主体时需明确指代，避免省略”；附录案例写有“镜头切到男孩的近景”“镜头切回女孩的中近景”。“运镜写法”允许直接使用标准景别术语，没有规定必须使用“某某的中近景”这一固定句式。

- 按用户确认的写作约定，在景别描述中同时点明拍摄对象，优先写“固定机位，拍摄角色A的中近景”。“中近景，角色A缓缓转身”也能明确对象，不能仅因句式不同就判为违反官方要求。
- 使用已定义的主体标签；局部特写写清部位归属，如“角色A右手的特写”；多人镜头点明同框对象，如“角色A与角色B的双人中景”；道具、场景可直接作为对象，如“记录簿的特写”“车站全景”。
- 按叙事需要补充可见范围，例如保留完整头面与收袖动作空间，不将景别名称当作固定裁切保证。

### 分镜顺序

- 复杂视频按镜头1、镜头2等事件顺序写；一个镜头可包含摄影方式、动作表情、位置变化、对应声音。
- **默认不写 0–3 秒这类强制分段时间戳**。指南说明精确时间支持不稳定，应让剧情自然决定节奏。
- 用户给了总时长，保留为制作目标或平台设置；据此压缩镜头数量与剧情密度。用户需要秒表式规划时，可另列“制作节奏参考”，不要宣称它能精确约束模型。
- 同一镜头尽量选择一种主要运镜方式，使用通行术语，避免把推、拉、摇、移同时堆在一起。
- 官方明确推荐“运镜/切换→主体动作表情→空间变化→对应声音”的镜头内组织。复杂片段按镜头序号展开；单镜头用自然段是本技能的精简选择，不能把镜头序号说成官方禁止或必须凑满三个。

### 动作和情绪

- 指定参与动作的身体部位，补足速度、幅度和力度；写出动作之间的自然承接。
- 官方优先建议幅度较小、速度低缓的连续动作。这是稳定性建议，不应把用户明确要求的打斗、奔跑或舞蹈擅自改成静态文戏；此时精简动作链，可结合动作参考或分段创作。
- 情绪用可见行为表达，如呼吸、手指、肩背、视线和面部变化，而不只写“很悲伤”“非常紧张”。

### 质感和约束

- 明确整体美术类型、色调、光影与纹理质感，保持前后一致。
- 字幕、文字、Logo、水印等限制按用户需求添加。用户要求出现标题或品牌标识时，不能再附带“无任何文字/Logo”。
- 没有必要把所有修复词和负面词复制到每条提示词；只处理当前场景的问题。

## 声音与文字

来源章节：注意事项、文字生成、音色参考不准、中文发音不准。

| 内容 | 官方建议的标注形式 | 使用方法 |
|---|---|---|
| 背景音乐 | 全角圆括号 `（）` | 说明风格、节奏、出现关系。 |
| 音效 | 尖括号 `<>` | 绑定画面事件，如 `<杯底轻触木桌声>`。 |
| 台词 | 花括号 `{}` | 前面写清说话人；非中英文台词注明语种。 |
| 字幕 | 方头括号 `【】` | 写清文字与出现要求，避免与禁止字幕的约束冲突。 |

- 台词尽量保持同一种语言，专有名词可例外；不要无端把用户台词翻译成英文。
- 音色参考不稳定时，补充可辨识的声音特征，并使台词语气接近参考音频。
- 广告语/标题写明内容、出现时机、位置、呈现方式及字形色彩；普通常用字更适合。
- 字幕可注明与说话内容同步；气泡台词要说明哪位说话者周边出现哪段文字。
- 必须准确保留的名称不擅自改字。需要处理发音时，可另给同音字语音优化方案，并说明与屏幕显示原文分开处理。

## 素材组织与问题定位

来源章节：素材配置策略、常见问题、附录案例。

- 官方常用配置是少量角色图、场景图、运镜视频和音频组合，不建议为了用满上限而堆素材；纯文生视频无需补造素材要求。
- 人物身份不稳：优先独立人脸近照与全身造型图，分别指定脸部和服装用途，重要来源靠前。
- 人物三视图拼在一张图、多人绑定不清容易造成重复角色。人物场景优先单人独立图；商品多角度参考则在附录有对应示例，不应把人物的避坑建议扩大成禁止所有多视角素材。
- 人数较多：官方指出超过四个参考人物时稳定性可能下降，可先按组制作人物图片，再据分组图片生成视频。这是优化策略，不是四人硬上限。
- 风格漂移：明确具体媒介和画风，必要时先把参考图统一到目标画风。
- 特定特效的文字控制不准：使用确切特效视频作为该维度参考。
- 重复延长会累积质感损失；减少续写次数、保留高清图参考。原文也给出先转成白模再续写的缓解思路，仅在用户遇到该问题时讨论。
- 单场景对话适合连续延长；复杂转折、追逐和打斗可分段生成后拼接。延长输出不重复生成整个原片，不能把输出承诺成“原片加新片的完整成片”。
- 原文轨道补齐示例说明最多三段视频、合计不超过十五秒；这是当时文档的输入限制，实际执行或回答最新规格前重新核实，不能套到其他版本。
- 衔接跳变与片尾声音截断可能需要后期处理，不承诺仅靠提示词完全消除。

## 从案例提炼的写作风格

官方案例常以素材用途开场，紧接具体场景与事件，再用镜头顺序铺开，末尾统一风格与声音。新提示词应模仿这种组织逻辑，并使用用户自己的剧情；不要照搬案例中的人物、品牌和台词。参考任务的素材绑定是这套组织逻辑的一部分，不能只学到电影质感、景别等词汇。简单单镜头可直接用连贯短段写完，不必展开成拍摄执行表。

示例与正文建议若有局部张力（如某案例单镜头用了多种运镜），默认优先正文明确建议，按当前需求简化。
