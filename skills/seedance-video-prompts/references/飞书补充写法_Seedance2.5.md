# Seedance 2.5 飞书官方补充写法

来源：[Seedance 2.5 提示词撰写指南](https://bytedance.larkoffice.com/docx/OsiUdR1OxoDqvnxsK8LczYx7nPd)。2026-09-12通过正常访客会话的curl请求获得HTML及分页正文，共515个文档块，已按文档顺序读取全部段落和表格；排除评论、账号信息和页面会话配置。本页为规则归纳，不是原文副本。

本文多数规则已与[官网知识](官方写作知识_Seedance2.5.md)和[官方技能编排](素材与任务编排_Seedance2.5.md)一致，以下保留具体补充及官方差异。

## 基础、素材与声音

- 主体＋动作/事件是必需内容，场景、视觉、摄影、声音按任务选择，不必填满模板。动作概括主过程，只突出关键细节。
- 多素材写明每份实际采用什么；只有容易把人物、背景或构图带错时才写不采用项。素材分组顺序为逐份职责→主体映射→按类型分组→重要主体设定→按场景调用。
- 主体自身左右与画面左右是不同坐标，必要时结合姿态明确对应；不要只给“画面左侧”而失去稳定空间关系。
- 声音可以自然语言描述，也可用音乐`()`、音效`<>`、对白`{}`、字幕`【】`；非中文对白建议标明语言。地区变体/口音只按用户要求或实际问题加强，不自动替用户选择。
- 当`<>`已作音效标记时，成品主体名用普通姓名，避免与来源模板里的尖括号占位符混用。用户确认的无栏目、素材每行排版继续保留。

## 一键成片

比“把素材做成视频”更完整的组织：**素材职责→图片顺序→动态幅度→剪辑风格→视觉包装→声音**。

- 顺序重要时逐张指定；允许重排时明确“按主题自由编排”。人物、商品、地点及事件关系仍保持对应。
- 图片动态可选轻微Live动作、视差、推拉、横移或局部动作，明确保留的结构与文字，不把静态图片自由改成新剧情。
- 风格参考视频可以只负责剪辑节奏、转场、贴纸或音乐风格，不默认继承该视频人物与地点。
- 视觉包装写位置与作用；用户需要贴纸或字幕时，不能附带与之冲突的通用限制。

## 无缝转场

按**转场前视频→转场后视频→触发动作→镜头运动→画面变化→到达状态→声音**组织。

| 方法 | 必须明确的可见变化 |
|---|---|
| 俯冲/折返 | 镜头方向、速度转折、进入下一场景的时机 |
| 人物旋转 | 旋转方向、姿态，以及衣装/背景如何连续变化 |
| 前景遮挡 | 遮挡物何时覆盖全屏、遮挡后出现什么构图 |
| 物体变形 | 前后对象对应的形状、材质和变化过程 |
| 推拉/移焦 | 镜头路径、焦点对象、前后空间的连续关系 |

原创简式：

```text
@视频1 提供转场前片段的尾部主体、构图、运动方向与声音。
@视频2 提供转场后片段的开头主体、构图、运动方向与声音。
在 @视频1 尾部，〔具体动作或遮挡〕触发转场，镜头〔方向与速度〕，〔前段形状/材质/光线〕逐渐变化为〔后段对应元素〕，自然到达 @视频2 的开头状态。
声音从〔前段声源〕平滑过渡到〔后段声源〕。
```

只填写当前素材可观察、用户需要的变化。自然过渡不等于两段原片逐像素不变。

## 表演与摄影

单次情绪转折通常挑2–4个清楚表现，按触发事件→即时反应→后续变化→最终表现；这是细节选择建议，不是每条必须写四种微表情。多次情绪变化再分阶段。

| 摄影方式 | 具体说明 |
|---|---|
| 希区柯克变焦 | 主体大小保持怎样，背景空间被拉近或推远 |
| 航拍 | 高度、移动方向、环境范围 |
| FPV | 第一人称穿行路径、速度与转向 |
| 子弹时间 | 哪个动作冻结/放慢，镜头向哪侧环绕 |
| 回弹变速 | 在哪个动作节点加速、减速或回弹，最终停留状态 |
| 浅景深 | 哪个主体或部位清晰，哪些背景虚化 |
| 追随摄影 | 镜头与主体的同速关系，背景拖影方向 |
| 黄金时刻 | 暖色低角度光从哪侧照入，阴影走向 |
| 自然暗角 | 四角渐暗，中心主体正常，无意外黑框 |
| 甩镜转场 | 触发时刻、遮挡物、方向、切换后构图及运动趋势 |

摄影数值可辅助，但可见结果比单独写光圈、焦距、快门更明确。

## 关键帧与参数差异

飞书版“首尾帧与参考素材”写：在全模态模式直接用文字指定首尾帧，也会按首帧锁定画幅。这与官网主指南的“reference_image语义参考不锁定”和API互斥输入规则冲突。

保留差异，实际执行按[生成参数与素材限制](生成参数与素材限制.md)：严格首尾帧需设置对应角色；全模态加文字首尾要求是语义参考，不能据飞书文字承诺锁定画幅或逐帧一致。飞书编辑误差约0.3秒与当前API约0.4秒也继续分别标明。
