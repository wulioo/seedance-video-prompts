# 官方写作知识：Seedance 2.5

主要写作依据：[Doubao Seedance 2.5 提示词指南](https://docs.volcengine.com/docs/82379/2607689?lang=zh)。核验日期：2026-09-12；官方更新时间：2026-09-07。本页独立归纳2.5正文；已读取主指南明确推荐的官方`sd25-pe 0.1.1`，补充见[素材与任务编排](素材与任务编排_Seedance2.5.md)。接口与输入边界见[生成参数与素材限制](生成参数与素材限制.md)。模板栏目与原创例子为本技能定制，并非官方逐字模板。

## 结构与素材指代

来源章节：提示词写作建议 → 基础写作、参考类。

提示词按四部分组织：**素材用途映射 → 一句话概述 → 按镜头或时间轴展开的情节 → 贯穿全片的要求**。

- 概述交代主体、地点、事件、题材或风格，以及重要摄影特征。
- 每份图片、音频、视频都按上传顺序编号，并写出用途；只在图片上写人名不构成充分的文字映射。
- 多角色需逐一绑定外观和音色；部分参考应具体说明提取哪个部分。
- 主体可以是人物、动物、道具、场所等。同一人物多视角应逐图说明职责并共同定义一个身份；不同命名角色不可用单人图混为一个主体。用户明确的引用和职责优先，实际已提供但未采用的素材按编号标明，详见编排补充。
- 素材本身精确表达动作或摄影方式时，明确指代即可，不必逐帧复述，避免文字与视频冲突。
- 正文优先用正向描述，补充全局机位、环境、氛围和声音。字幕与声音有明确的负向控制支持。

## 时间、动作与镜头

来源章节：时间戳、负向控制、进阶写作。

### 时间组织

- 可使用镜头序号，也可用**整数秒**时间戳；用户强调节奏、时长或局部编辑时适合时间轴。
- 使用时间轴时写覆盖目标片段的连续区间，如 0–4秒、4–9秒、9–15秒。避免无意遗漏或重叠；不要把每条短视频机械切成固定三段。官方技能建议普通任务用镜头/阶段，仅在用户给出或需要时间控制时加入数字时间段；主指南允许时间轴，两者不是“支持/不支持”的冲突。
- 也支持具体时间点和相对时间，如一个动作发生后停顿一秒。
- 情节太少可能出现自由补充，太多可能过度剪切或遗漏。按时长控制叙事负荷，不用时间戳强控“一秒做三次”之类频率。

### 表演与摄影

- 动作先概括整体行为，只对少数关键动作写细节，不机械拆解所有肢体步骤，也不重复同一动作。
- 表情用可观察的描述性语句，减少成语式概括。
- 通行景别、运镜、机位和热门摄影方式可直接写；少见专业术语要加清楚的画面解释。
- 转场交代触发时机、运动方向和转换方式；一镜到底的要求不能与无意加入的跳切冲突。
- 参考镜头已有清楚的摄影设计时，不再添加相反的运镜指令。

### 声音和文字

- 对白、音效、环境声、音乐分清来源、发生时机和关联主体。
- 可分别控制是否保留对白、音乐和音效，也可明确整片静音；“没有背景音乐”不等于没有任何声音。
- 不需要字幕时明确说明；需要字幕时注明内容与同步目标。
- 采用清楚的自然语言或“台词（角色）：……”即可。2.5官方教程“提示词规则”和`sd25-pe`均列出音乐`()`、音效`<>`、台词`{}`、字幕`【】`，可按需采用，不必从2.0借规则。没有某符号并不代表指令无效，不把示例符号说成强制协议。

## 任务类型决定素材是否锁定输出

来源章节：任务使用说明、编辑类、首尾帧。

此处是平台/API 设置知识，**不可把参数混进提示词并宣称它们已被设置**。

| 任务 | 提示词与素材角色 | 实际参数要求或影响 |
|---|---|---|
| 编辑原视频 | 点名待编辑视频及增删改目标，可写具体时间区间；相关素材使用 reference 类型角色。 | `ratio=adaptive`，`duration=-1`；画幅跟随待编辑视频，时长基本跟随原视频；建议 MOV。 |
| 首帧/首尾帧 | 首尾图分别通过 `content.role=first_frame/last_frame` 指定。 | `ratio=adaptive`；画幅由首帧图锁定；时长可设。首尾图应同画幅，避免尾图被拉伸。 |
| 向前/向后延长 | 使用延长、延续或续写等明确意图，点名待延长视频；相关素材用 reference 类型角色。 | `ratio=adaptive`；时长可设；输入与输出均推荐 MOV。 |
| 语义参考生新视频 | 指定素材参考维度，描述新内容。 | 输入素材不锁定输出画幅、时长。 |
| 图片仅作为首尾参考 | 图片角色为 `reference_image`，正文说用作首帧或尾帧。 | 属于语义参考，不锁定画幅，结果可相似但不保证严格匹配。 |
| 多宫格故事板、独立关键帧参考 | 见下节。 | 均属于不锁定输出属性的参考任务。 |

- 编辑用明确“编辑/增加/删除/替换”等意图，描述原状态到新状态，标出范围及应保留的内容；有多段输入时明确目标视频，避免模型选错。
- 提示词主指南/官方技能写编辑时长偏差最大约0.3秒，当前API/教程写约0.4秒；主指南另称本模型产物作编辑输入时无此差距。实际调用以API/教程为准，交付不保证所有输入逐帧等长，也不把0.3秒当改任务类型的通用硬阈值。
- 对已有视频要改画幅或时长时，不应同时承诺严格原片编辑与自由输出参数。解释其锁定关系，再给符合用户目标的任务方案。
- API明确首帧图生、首尾帧图生、全模态参考互斥，不能混传`first_frame/last_frame`与任意参考素材。严格首尾帧用对应角色；更多参考与首尾效果组合走语义参考，并说明差异。
- 实际提交可使用`omni_reference_task_type=reference/edit/extend`或`auto`；它不能替代明确的任务提示词。意图不一致可能触发TaskTypeMismatch，限制不满足可能触发TaskTypeConstraint。编辑母版必须4–30秒。

## 专项参考写法

来源章节：白模参考/渲染、多宫格分镜/故事板、关键帧参考、提示词案例。

### 白模

- 列出需要继承的动态信息：运镜、动作、动线、光照变化等；再定义最终场景、角色、材质、风格。
- 配套参考图与白模角色/物体逐一对应。没有外观图的对象用文字说明外观，整体剧情与白模保持一致。
- 简单几何体拼合的粗粒度白模是官方推荐起点。精细四肢或翅膀若没有完整动作，可能导致僵化。
- 细粒度白模应排除轨迹线、坐标线和相机锥等辅助显示，避免它们进入成片。

### 故事板与关键帧

- 多宫格图提供剧情和构图方向，不保证严格逐格复现；官方建议少于十五格、简洁线稿、不要在图上堆文字。
- 线稿故事板：先绑定素材，写故事概述，再补全各镜头缺少的动作、运镜、风格；可配连续时间轴。
- 不推荐杂乱、过度锐化的AI直出分镜图；明确格子读取顺序，避免辅助文字和占位画风进入最终画面。
- 概念分镜表达充分时可以简写，不强制把图中内容全部重述。
- 要更贴近每张构图，改用**多张独立图片**按顺序作为关键帧。开头写清“以图片1至图片N的顺序作为关键帧”；有非连续编号时列出准确顺序。按实际上传编号填写，不把一张多宫格图冒充多张独立输入。
- 关键帧的较强画面对齐，不等于通过 first_frame/last_frame 参数触发的首尾帧锁定。

### 其他任务

- 延长：写清方向、增加的剧情、承接画面和声音；原文提醒音量仍可能轻微变化，不承诺绝对无缝。
- 一键成片：说明素材顺序是否可重排、统一风格、转场和声音；按用户要求明确对原素材内容的保留程度。
- 无缝转场：指明前后两段视频、衔接动作、镜头路径和变化过程，不把它写成只借用视频风格。
- 原生多语言：2.5教程列出中文、英语、西班牙语、印度尼西亚语、葡萄牙语、日语、马来语、泰语、阿拉伯语、越南语、韩语，共11种；按用户语言与口音要求逐个说话人标注，不从外观猜口音。

## 素材规模：硬上限和推荐量分开

来源章节：总体介绍、素材输入建议。以下为核验日快照；用户询问最新规格或准备实际调用时需再次核实官方资料。

- 单段输出最长三十秒；总参考素材最多五十个。
- 图片最多三十张，单图不高于4K；视频最多十段且总时长不超过三十秒；音频最多十段且总时长不超过三十秒。总数和各类限制应同时满足。
- 主体音视频以一至五个主体、五至十秒较稳；主体图以一至八个主体较稳。更多不是绝对不支持，而是稳定性可能下降。
- 一至五个主体可用单视图或多视图；超过五个时单视图较稳，多视角宜拆成独立图片。
- 编辑输入以二十秒以内较稳，参考图编辑以一至五张较稳；不是把二十秒或五张当成硬限制。
